# Kridge System Architecture Overview

Kridge connects unused enterprise and individual AI subscriptions with autonomous AI agents and developers.

## Core Pillars
1. **GenLayer Intelligent Contracts**: Web-connected validators that probe API keys and arbitrate subjective quality disputes using LLMs.
2. **Ephemeral Virtual Sub-Keys**: Zero raw API key exposure via proxy gateway.
3. **Hyperlane Interchain Messaging**: Cross-chain settlement from Base, zkSync, and Solana.
4. **ESG Proof-of-Donation Badges**: 6-tier on-chain NFT progression.
